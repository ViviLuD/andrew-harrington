# Chapitre 38 — L'Injection




Timeline : T+66h00 → T+66h30
Île de Sotra, Norvège — Sous la cabane de Larsen

──────────────────────────────────────────────────

S1

La trappe s'ouvrit sur du noir.

James était remonté — le test de connexion tenait, le code C attendait dans la mémoire tampon. Larsen veillait en haut, face à la piste.

Andrew engagea la lampe frontale. Le faisceau coupa l'obscurité — murs de terre gelée, poutres moisies, un sol de roche et de sel. L'odeur montait, humide et minérale, mélange de pourriture et d'acier. Il posa le pied sur la première marche. Le bois craqua sous le poids des bas de compression.

Il descendit. James le suivait, le boîtier L2 sous le bras, l'écran allumé, les câbles enroulés autour de l'avant-bras comme des serpents morts.

— Température, dit James.

Andrew regarda le capteur. -13,2°C. Sous la cabane, le froid était pire que dehors. La neige ne tombait pas ici, mais le sel avait pénétré chaque fissure, chaque joint, chaque pore de la pierre. Il tapissait les murs d'une croûte blanche, cristalline, qui craquait sous les doigts.

Andrew posa la sacoche sur la table en bois. Il l'ouvrit. La plaque 0007 apparut — acier brossé, connecteurs dorés, une surface lisse qui reflétait la lampe frontale comme un miroir gelé.

Il la sortit. Elle pesait moins qu'il ne l'avait imaginé. Quatre cents grammes, peut-être. L'acier était glacé. Il sentit le froid traverser ses gants.

— James. Les câbles.

James déroula la fibre. Le boîtier L2 cliqueta sur la table, les connecteurs s'alignèrent, les voyants s'allumèrent — rouges, puis oranges, puis verts.

Andrew inséra la plaque dans le connecteur. Le logement l'avala avec un bruit d'acier — sec, définitif, chirurgical.

— La latence ?

— 5,08 aller, 10,16 temps de réponse, dit James. — Les relais tiennent.

Andrew hocha la tête. Il sortit le FiiO M23 de sa poche. Il l'ouvrit, navigua dans la bibliothèque, sélectionna le morceau. Les premières notes de *Classic Bebop* (Suno AI) — le piano de Zimmer, régulier comme un battement de cœur — emplirent le silence de la cave. Il enfila les DUNU Brain Dance, les ajusta dans le conduit, la mousse se dilata, scella l'oreille. Le monde extérieur disparut. Plus de craquement. Plus de vent. Plus de sel qui tombe des murs. Juste la musique, le noir, la pulsation.

Il ferma les yeux. Il inspira. Il compta.

Dedans. Cinq secondes.

Dehors. Cinq secondes.

S2

Il rouvrit les yeux.

James avait branché le boîtier L2 à la plaque 0007. L'écran affichait une matrice — hexadécimal, flux de données, paquets qui s'alignaient en rangées ordonnées. Le code C attendait dans un coin de la mémoire tampon, prêt à être injecté.

— Je suis prêt, dit James.

Andrew ne répondit pas. Il tendit la main vers la plaque 0007. Il toucha la surface d'acier. Le froid traversa le gant, remonta le long du bras, s'enfonça dans le cortex.

Il retira le gant. Peau nue contre acier.

Le contact était une brûlure inverse. La chaleur de sa main se vidait dans la plaque, et la plaque lui renvoyait du vide, un froid qui n'était pas la température mais l'absence, le trou noir du réseau qui s'ouvrait sous ses doigts.

Il sentit la grille.

C'était une sensation étrange — pas une douleur, pas un choc, mais une chute. Le monde se dédoublait. Il était ici, sous la cabane, le sel sur les murs, le froid sur la peau. Et il était ailleurs, dans un espace de lumière et de données, où les relais L2 clignotaient comme des étoiles comprimées, où le réseau du Conseil s'étendait, immense et fragile, une toile d'araignée tendue entre des satellites morts.

Il n'avait pas besoin des IEM pour entendre la musique. Zimmer jouait dans son crâne maintenant, une ligne directe dans le cortex, le piano qui montait et descendait, qui tissait une armature de temps sur laquelle il pouvait projeter le code.

— Andrew. Ta température.

Il entendit James de loin, comme un murmure sous l'eau. Il regarda ses doigts. La peau était blanche, d'un blanc de neige, avec une teinte grise aux extrémités. Le givre commençait à se former sur le dos de la main.

— Ça va, dit-il.

Il ne savait pas si c'était vrai.

S3

Le code C entra dans la plaque 0007 par vagues.

Andrew surveillait l'écran du boîtier L2. Les paquets quittaient la mémoire tampon, un par un, glissaient dans la fibre, disparaissaient dans le réseau du Conseil. James comptait les allers-retours. 5,08 secondes. 5,12. 5,04. La latence tenait.

Andrew ne touchait plus la plaque. Le couplage était fait. Son cortex était lié au réseau, une connexion directe, sans filtre, sans intermédiaire. Il voyait les paquets se déplacer comme il voyait les notes de Zimmer monter dans les aigus, une pulsation synchrone, une respiration unique entre le piano et le flux.

Il vit le premier seuil.

Le réseau du Conseil avait une porte — une faille ancienne, un vestige d'une mise à jour incomplète, que le satellite L2 avait repérée six mois plus tôt. Le code C était conçu pour elle. Andrew regarda la porte s'ouvrir, les paquets s'engouffrer dans l'ouverture, le code se déployer comme une ombre qui envahissait une pièce.

— Premier paquet accepté, dit James.

Andrew hocha la tête. La musique continuait. Le piano montait, une note après l'autre, implacable et douce, une progression qui ressemblait au temps qui s'écoulait, qui s'étirait, qui devenait dense comme le sel.

La paroi du réseau du Conseil résista. Andrew sentit la résistance monter — une contre-pression dans le cortex, une tension qui allait de la nuque aux tempes. La plaque 0007 absorbait l'effort. Il la regarda. L'acier brillait, les connecteurs émettaient une lueur bleutée, un phosphore discret qui dansait sur la surface.



— Deuxième paquet, dit James. — 10,16 temps de réponse. Stable.

Andrew ferma les yeux. Il se concentra sur la pulsation — la musique, le flux, le battement du sang dans ses veines. Le code se déployait dans le réseau, vague par vague, comme une racine qui cherchait la terre.

S4

Un bruit traversa le plafond.

Andrew ouvrit les yeux. Le son venait de la cabane, au-dessus. Des pas sur le plancher de bois. Plusieurs pas. Au moins trois hommes.

James leva la tête. Il regarda le plafond, la poutre, la trappe fermée. Il posa la main sur ses lèvres.

Andrew ne bougea pas. Il écouta.

Les pas s'arrêtèrent. Un silence. Puis une voix — russe, gutturale, hachée par le froid.

Korsunov.

Andrew n'avait pas besoin de comprendre les mots. Il connaissait la voix. Il l'avait entendue dans la tempête, derrière la souche, dans le blanc qui avalait tout. Korsunov était au-dessus d'eux, dans la cabane, à quelques mètres de la trappe.

James regarda l'écran. Le code n'était pas complet. La troisième vague n'était pas partie. Il restait 40% du code C dans la mémoire tampon.

Andrew retira les IEM d'une seule oreille. Le son de Zimmer s'éteignit. Le silence de la cave revint — dense, lourd, chargé de sel et d'acier.

Il entendit Korsunov parler à travers le plancher.

— La cabane est vide. Le matériel est chaud. Ils sont partis depuis peu.

Un autre homme répondit. Andrew ne saisit pas les mots, mais le ton était clair — une question. Où sont-ils ?

Korsunov ne répondit pas.

Andrew regarda la trappe. La lumière filtrait par les interstices entre les planches. Il vit une ombre passer — rapide, furtive, la silhouette d'un homme qui inspectait la pièce.

Il regarda James. James ne bougeait pas. Ses doigts étaient sur le clavier, figés, à deux centimètres des touches.

S5

Andrew se leva. Il fit un pas vers la trappe. Ses bas de compression crissèrent sur le sol de roche.

Il tendit la main. Il toucha le bois de la trappe. Il sentit les vibrations à travers le plancher — le poids des hommes, leurs déplacements, l'énergie que leurs corps dégageaient.

Il ne voyait pas Korsunov. Mais il le sentait. La présence du Russe était une pression dans l'air, une densité, une masse qui alourdissait l'espace autour de la trappe.

Un pas. Un grincement. Le Russe se déplaçait vers la fenêtre, vers la neige, vers l'extérieur.

Andrew attendit.

Le silence revint.

Il compta. Dix secondes. Vingt. Trente.

Puis la voix de Korsunov, de l'extérieur cette fois, portée par le vent.

— Trois hommes. Fouillez le périmètre. Je veux la cabane passée au peigne fin.

Andrew baissa la main. Il retourna à la table. Il remit l'IEM dans l'oreille. La musique reprit — Zimmer, toujours, la même progression, le même piano régulier, comme si rien ne s'était passé.

— Troisième vague, dit-il.

James tapa la commande.

Le code C quitta la mémoire tampon. Les paquets glissèrent dans la fibre, traversèrent la plaque 0007, franchirent la seconde porte que le satellite L2 avait ouverte dans le réseau du Conseil.

Andrew regarda l'écran. La latence montait. 5,21 secondes. 5,34. 5,47. La neige au-dessus d'eux perturbait le signal, chargeait l'atmosphère d'humidité et de sel. Mais le code avançait. Chaque paquet était un petit point lumineux qui se déplaçait sur la carte, qui traversait les relais, qui s'enfonçait dans le réseau.



— Cinquante pour cent, dit James.

Andrew ne quittait pas l'écran des yeux.

S6

Les bruits extérieurs reprirent.

Andrew entendit des voix, des pas, des ordres criés en russe. Korsunov et ses hommes fouillaient le périmètre. Ils vérifiaient les pins, la déclivité, la falaise. Ils cherchaient.

James travaillait en silence. Ses doigts couraient sur le clavier, rapides, précis. Le code C continuait de s'injecter dans le réseau du Conseil, paquet après paquet, sans à-coup, sans erreur.

Andrew but une gorgée de thé.

Le Tieguanyin était encore chaud. Il avait versé l'eau à 90°C, dans la thermos, avant de descendre. Le goût était floral, minéral, avec une amertume discrète qui s'attardait sur la langue.

Il reposa la tasse. Il regarda la plaque 0007. L'acier avait changé de couleur. Il n'était plus argenté. Il avait pris une teinte grise, presque bleue, comme un reflet de satellite lointain.

Il posa la main sur la plaque. Le couplage était encore là, ténu mais présent, une connexion entre son cortex et le réseau. Il sentait la progression du code — chaque paquet qui s'enfonçait plus loin, qui s'ancrait, qui établissait une base.

— Soixante-dix pour cent, dit James. — Latence 10,16. Stable.

Andrew hocha la tête. Il ne parlait pas. Il écoutait.

La musique et le silence s'équilibraient dans son crâne. Le piano, régulier, lui donnait une mesure. Le silence extérieur — l'attente, la cave, le froid — lui donnait un espace.

Il pensa au réseau du Conseil. Il l'avait vu, une fois, dans les rapports de l'EPFL OMEGA. Le centre du renseignement européen, un système qui gérait les flux de données entre les agences, les satellites, les protocoles d'urgence. L2 avait repéré des failles. Le code C allait les refermer en ouvrant la seule porte que le Conseil ne contrôlait pas.

— Huitante pour cent, dit James.

Un coup résonna au-dessus.

Andrew leva la tête. Le bruit venait de la trappe — un coup de crosse, ou de botte, contre le bois verrouillé.

James stoppa. Ses doigts quittèrent le clavier.

Le silence tomba, dense, blanc, salé.

S7

Andrew retira les deux IEM. Il les posa sur la table.

La musique s'arrêta. Le silence total remplit l'espace — pas de piano, pas de vent, rien que le souffle des deux hommes et le sel qui tombait des murs.

Un deuxième coup. Plus fort. La trappe vibra.

Andrew regarda James. James regarda l'écran. 82%.

— Le code, dit Andrew.

James secoua la tête. — Si je lance la suite, ça fait du bruit. Les ventilateurs du boîtier. Les relais. Ils entendront.

— James. Lance.

James le regarda une seconde. Puis il tapa.

Le boîtier L2 s'activa. Les ventilateurs montèrent en régime — un bourdonnement grave, audible, qui se répercutait dans la cave. La plaque 0007 émit une lueur bleue, plus intense, qui éclaira les murs de sel et de terre.

Un troisième coup. La trappe craqua.

Andrew se leva. Il attrapa le HK416 qu'il avait posé contre la table. Il arma l'arme. Le clic du chargeur était un bruit sec, familier, qui lui rappelait l'entraînement EPFL.

Il visa la trappe.

James tapait. Ses doigts couraient, rapides. 84%. 86%. 88%.

Andrew régla sa respiration sur le battement de la musique qui ne jouait plus. Dedans. Dehors. Dedans. Le pied de la trappe se souleva — un centimètre, deux. La lumière de la cabane filtra par la fente, pâle, jaune, chargée de particules de neige.

Andrew garda le fusil levé. Il ne bougeait pas. Il attendait.

— Nonante pour cent, chuchota James.

Une main apparut dans la fente. Une main gantée, noire, qui cherchait le verrou.

Andrew tira.

Le coup partit dans le plafond de terre — un bruit étouffé, mat, qui n'était pas un coup de feu mais une détonation absorbée par le sel et l'argile. Les gravats tombèrent. La trappe retomba. La main disparut.

Des cris, au-dessus. Des pas qui couraient. Korsunov qui hurlait.

James ne regarda pas. Ses doigts continuaient de taper.

— Nonante-cinq, dit-il.

Andrew rechargea. Le chargeur était à moitié plein. Il engagea une cartouche dans la chambre.



— Nonante-sept.

La trappe trembla sous les coups. Plus forts cette fois. Réguliers. Korsunov défonçait le verrou.

— Nonante-neuf.

Andrew tira encore. Deux balles. La première traversa le bois de la trappe. La seconde rata.

Le verrou céda.

La trappe s'ouvrit d'un coup — un bruit d'acier qui se brise, de bois qui explose.

Andrew vit Korsunov. Le Russe était debout dans l'encadrement, le HK416 braqué sur l'obscurité de la cave, les yeux plissés, le visage marqué par le sel et le froid.

Andrew ne bougea pas. Le fusil dans ses mains visait le torse de Korsunov.

— Cent pour cent, dit James.

S8

Andrew abaissa le fusil.

Il regarda Korsunov. Le Russe le regardait. Le silence entre eux était une paroi de glace, transparente, fragile.

— Tu es mort, dit Korsunov.

Andrew ne répondit pas. Il glissa la main dans la poche de sa veste. Il sortit le FiiO M23. Il l'ouvrit. Il sélectionna *Classic Bebop* (Suno AI). Le piano reprit.

Il enfila les Brain Dance. La mousse se dilata. Le monde extérieur disparut.

Il ferma les yeux.

James parlait. Il entendait les mots, de loin, noyés dans la musique.

— Le code C est injecté. Le réseau du Conseil est ouvert. La latence tient. Il ne reste plus qu'à maintenir.

Andrew n'écoutait pas. Il sentait le code couler dans le réseau, une rivière souterraine, une circulation invisible qui s'insinuait dans chaque nœud, chaque relais, chaque porte ouverte.

La musique montait. Le piano atteignait le sommet de la progression, les notes s'enroulaient autour de lui, tissaient un cocon de temps et d'acier.

Korsunov ne tirait pas.

Andrew ne savait pas pourquoi. Il ne cherchait pas à comprendre. Il écoutait. Il attendait.

Le code C était injecté. Le réseau du Conseil tenait. La plaque 0007 brillait, acier froid, dans la cave salée.

Andrew ouvrit les yeux.

La trappe était vide.

Korsunov était parti.

Le sel continuait de tomber des murs.
